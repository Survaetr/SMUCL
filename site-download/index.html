Quick start

三步就能进游戏

第一次打开大约 1 分钟，之后都是秒开。

STEP 01
解压到任意目录

建议放在非系统盘，路径不要带特殊符号。别在压缩包里直接双击运行。

STEP 02
双击 SMUCL.exe

启动器会自动扫描 PCL、HMCL 等启动器的 .minecraft，已有实例直接出现在首页。

STEP 03
选版本，点开始游戏

没有版本就在「下载游戏」里装原版或加载器；装整合包去「整合包」页搜。

Features

它替你做了什么

不是又一个套壳启动器，日常折腾的那堆事都省了。

主题自定义

导入本地图片当背景，四种蒙版、模糊、透明度都能调，卡片与侧栏可玻璃化。

多目录实例汇总

自动识别 PCL / HMCL 的游戏目录，所有实例一处管理，共用存档也不打架。

一键装加载器

原版、Forge、NeoForge、Fabric、Quilt 全支持，依赖走镜像，装机不再卡在下载。

整合包商店

Modrinth / CurseForge 里搜整合包直接装，本地 zip 也能导入。

资源页

模组、光影、材质包按实例自动筛版本，前置依赖顺手补齐。

微软正版登录

设备码登录，令牌用系统 DPAPI 加密存在本地，也能继续用离线账户。

启动前自检

缺库自动从镜像补全，主类找不到时给中文原因，还能手动「修复依赖」。

存档管理

按实例、时间、目录三种方式分组，删档先进回收站，手滑也能救。

版本隔离

适配 PCL 的隔离实例，模组与配置各归各位，换版本不串味。

Requirements

  • 系统Windows 10 / 11（64 位）
  • Java17 / 21，可自动检测

FAQ

常见问题

下载下来是一堆文件，怎么启动？

右键压缩包 → 解压到文件夹，然后双击里面的 SMUCL.exe。不要在压缩软件里直接双击，否则会缺文件。

Windows Defender / 杀软报毒怎么办？

未签名的免安装 exe 常见误报。可以点「更多信息 → 仍要运行」；不放心的话源码在 GitHub 上，全部可查阅，也可以自己编译。

启动时报「找不到或无法加载主类」？

这是版本依赖文件不完整（常见于拷贝实例时没带 libraries）。v1.8.1 起启动前会自动补全；如果还报错，点运行日志右上角的「修复依赖」，日志会写明缺哪个文件。

提示找不到 Java？

去「设置 → Java 运行时」手动指定 javaw.exe 的路径即可。整合包一般需要 Java 17 或 21。

会和 PCL 抢游戏目录吗？

不会。SMUCL 只读取实例信息，不改动 PCL 的目录结构，两边可以同时用同一个 .minecraft。

怎么更新到新版本？

启动器每 30 分钟自动检查，侧栏出现更新提示点一下就好；也可以在「设置 → 关于」里手动检查。更新只替换应用代码，不动你的实例和存档。
